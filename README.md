# DDS Frame

[日本語](README.ja.md) | English

DDS-native communication frame for Python device-control objects. It offers request/reply and publish/subscribe without requiring ROS 2. The current implementation is experimental and is not verified against a live DDS network.

## Installation

```bash
pip install .
```
