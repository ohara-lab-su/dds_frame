DDS-native Python communication frame, independent of ROS 2. Synchronous RPC and publish/subscribe are provided using CycloneDDS. This is an initial implementation, not a DDS router.

```bash
python -m pip install .
```

See [Japanese README](README.ja.md) and [documentation](https://ohara-lab-su.github.io/dds_frame/en/).
